# Data (not versioned)

- **eBird Basic Dataset (EBD)** and sampling-event file for the species/region (request access at https://ebird.org/data/download — not redistributable).
- Climate rasters, e.g. CHELSA bio1 / bio12 (1981-2010, v2.1).
- Ecoregion shapefile and/or a GeoJSON polygon of the area of interest.
